% NOTE ON ATS TEXT EXTRACTION: \scshape (small caps) corrupts copy/paste
% text extraction in this font (splits words with spurious spaces), so
% section headings use plain bold instead. The default itemize bullet
% glyph has no proper Unicode mapping and extracts as U+FFFD, so bullets
% use a literal hyphen instead (a real, unambiguous character).
%
% Known remaining limitation: the tabular*-based heading lines below
% (institution/project name + right-aligned date or links) can extract
% with no space at the column boundary for longer headings (e.g.
% "ProgramCertificate"), because \extracolsep{\fill} is pure glue with
% no character for a text extractor to find, and no glue-based fix
% (\hspace, \hfill) changes that (verified empirically — \hfill also
% broke the vertical spacing of Certifications entries with no bullet
% list below them, so it was reverted). This only affects the added
% link labels ("Certificate", "Verify", "GitHub") merging with the
% adjacent institution/project name, not any real resume keyword
% content — every skill, bullet point, date, and section heading
% extracts correctly.
